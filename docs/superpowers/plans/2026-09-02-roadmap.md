# 跨平台流媒体歌单导出工具路线图

本项目按以下独立计划顺序实施，每个计划必须产生可运行、可验证的增量：

1. `2026-09-02-core-netease-mvp.md`：共享核心、导出器、网易公开歌单、Web/PWA、NAS。
2. QQ Provider 计划：只有在取得公开 >1000 首歌单和可重复的分页证据后编写。
3. Apple Provider 计划：文件导入先行；官方 API 计划在 BYO token PoC 后编写；会话模式单独计划。
4. Tauri 计划：在共享核心和至少一个真实 Provider 通过后，分别覆盖 desktop 与 Android。
5. 发布计划：CI、安装产物、多架构 Docker、安全审查、许可证和文档。

阻断门失败时不伪造实现：对应能力保持 `Experimental` 或 `Unavailable`，其余已验证能力继续发布。
